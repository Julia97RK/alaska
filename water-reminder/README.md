# 💧 Попей воды

Простое веб-приложение, которое напоминает пить воду.

**Открыть:** https://julia97rk.github.io/alaska/water-reminder/

- напоминание каждые N минут (уведомление, звук, баннер);
- счётчик стаканов и цель на день;
- активные часы (например, 09:00–22:00);
- всё хранится в браузере, без сервера.

Напоминания работают, пока страница открыта (можно в фоновой вкладке).
